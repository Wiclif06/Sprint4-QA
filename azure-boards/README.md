# Plano no Azure Boards

49 casos publicados, IDs 510–558, ligados aos respectivos PBIs. São 48 casos na Sprint 4 e CT029 complementar, fora das entregas 3 e 4 conforme o PBI 402.

- `casos_publicados.csv`: IDs, pais e links dos casos.
- `atualizar_conteudo_casos.csv`: descrições e iterações atuais para atualização pelos mesmos IDs.
- `backlog_observado_2026-10-26.csv`: referência do backlog anterior ao cadastro dos casos.
- `exportacao_casos_2026-10-26.csv`: referência dos IDs e títulos publicados.

Os casos são tarefas do Azure Boards com objetivos, entradas, saídas e passos na descrição. Não reimporte uma lista de criação: isso duplicaria os casos. A atualização não depende de novas etiquetas.
