# Casos no Azure Boards

Os 49 casos já foram cadastrados (IDs 510–558), vinculados aos requisitos e configurados na Sprint 4. O arquivo casos_publicados.csv contém os links individuais. A conta usada permite editar itens, mas não criar novas etiquetas; a atualização foi concluída sem etiquetas.

A importação inicial foi realizada em duas etapas para preservar os requisitos existentes: criação da hierarquia apenas com IDs e títulos, depois atualização de conteúdo somente dos novos casos. Não reimportar uma lista de criação, pois isso duplicaria casos.

atualizar_conteudo_casos.csv contém os IDs já publicados e serve para atualizar esses mesmos casos. backlog_observado_2026-10-26.csv é um retrato dos itens anteriores, sem e-mails. exportacao_casos_2026-10-26.csv confirma os IDs e títulos persistidos; o exportador padrão não inclui Description. O conteúdo e o vínculo foram conferidos também no formulário do caso 514, com captura em evidencias/prints.
